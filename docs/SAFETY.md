# 安全使用說明

## 一、使用前確認

使用本工具前，請先確認下列事項：

1. 文件來源可信。
2. 本機 Microsoft Office 或 LibreOffice/OpenOffice/OxOffice 已正確安裝與啟用。
3. 第一次使用 Office 時，建議先手動開啟 Word、Excel、PowerPoint，完成授權與首次啟動設定。
4. 若文件從網路下載，可能會被 Windows 或 Office 標記為受保護檢視，背景轉檔可能失敗。

## 二、文件安全建議

不建議直接轉換下列文件：

- 來源不明的 Office 檔案。
- 來自陌生寄件者的附件。
- 要求啟用巨集的文件。
- 開啟時要求輸入帳號密碼或更新外部連結的文件。
- 可能包含惡意嵌入物件的文件。

## 三、巨集與外部連結

本工具在 Microsoft Office 自動化時會嘗試設定 `AutomationSecurity = 3`，並以唯讀方式開啟文件，降低巨集自動化執行的風險。

但這不是完整沙盒機制。處理不可信文件時，請使用虛擬機器或獨立測試環境。

## 四、隱私

本工具不會主動連線到網路，也不會將文件傳送到任何伺服器。所有轉檔均透過本機已安裝軟體執行。

## 五、校內或企業部署建議

若要部署給校內或企業同仁使用，建議：

1. 先在標準映像機測試。
2. 確認 Office 授權與版本一致。
3. 確認 LibreOffice/OpenOffice/OxOffice 備援引擎是否需要安裝。
4. 建議透過 IT 部門提供已審核的 ZIP 或內部軟體派送。
5. 不建議讓使用者自行修改腳本內容。
